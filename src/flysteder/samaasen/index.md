Selve urstedet i Harstad-regionen, med flyging siden 1976. Et lite hang nord for byen som kan være smooth som fløyel, og turbulent i vestlig vind.

## Start

Start rett ved veien på toppen. Bratt, kort og ikke særlig jevn, så den krever vind inn og brukes bare i hangforhold. Derfor PP3.

## Landing

Landingen er litt rotete. Ikke land på åkrene til bonden under starten.
