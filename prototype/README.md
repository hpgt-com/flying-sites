# Prototype: flyplattform

Klikkbar skisse av hvordan flysteder.hpgt.com kan utvides med værstasjoner, historikk per start, flylogg og klubbstatistikk. Ligger utenfor `src/`, så den bygges ikke og publiseres ikke med siden.

Åpne `plattform.html` i en nettleser. Startene er ekte (fra stedsfilene), men værmålinger, stasjoner og flyturer er eksempeldata med fiktive piloter. Kartet er skjematisk. IGC-opplastingen under «Min logg» leser en ekte fil lokalt i nettleseren, men lagrer ingenting.

Fanen «Bygge eller integrere?» har anbefalingen: hva klubben bør bygge selv, hva den bør hente fra andre, og i hvilken rekkefølge.
