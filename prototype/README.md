# Prototype: flyplattform

Klikkbar skisse av hvordan flysteder.hpgt.com kan utvides med målt vind fra værstasjoner, vindhistorikk per start og klubbstatistikk. Ligger utenfor `src/`, så den bygges ikke og publiseres ikke med siden.

Åpne `plattform.html` i en nettleser. Linjen øverst blar mellom skjermene: forsiden (Vær-fanen og «Målt» i vindvalget), stedssiden, en værstasjon, klubben, min side og anbefalingen.

- Flystedene er ekte (navn, posisjon, retninger, nivå og innledning fra stedsfilene). Værmålinger, stasjoner og turer er eksempeldata med fiktive piloter.
- Oppsett, farger, vindrosen og vurderingen («Kan passe», «Usikkert», «For mye vind», «Passer ikke») følger siden slik den er i dag, også mørk modus og fargeblindvennlige farger.
- Kartet er skjematisk. På siden ligger Kartverket under.
- Turene hentes fra Flightlog og XContest for medlemmer som kobler til kontoen sin. Ingen logger noe på siden.
